ChemDoodle Web Components – Integration

This application integrates ChemDoodle Web Components to provide an in-browser 2D structure editor, a 3D WebGL viewer, and a periodic table widget.

CDN includes

<link rel="stylesheet" href="https://web.chemdoodle.com/assets/css/ChemDoodleWeb.css" />
<script src="https://web.chemdoodle.com/assets/js/ChemDoodleWeb.js"></script>
<script src="https://web.chemdoodle.com/assets/js/ChemDoodleWeb-uis.js"></script>

Components used

  • StructureEditorCanvas – 2D drawing and editing
  • TransformCanvas3D – WebGL-based interactive 3D viewer
  • PeriodicTableCanvas – interactive periodic table

Instantiating components

const editor = new ChemDoodle.StructureEditorCanvas('cdEditor', 520, 300);
const viewer3d = new ChemDoodle.TransformCanvas3D('cd3d', 520, 300);
const pt = new ChemDoodle.PeriodicTableCanvas('cdPT', 520, 300);

Loading molecules

From SMILES:

const mol = ChemDoodle.readSMILES('C1=CC=CC=C1');
editor.loadMolecule(mol);

From SDF/MOL text (e.g., PubChem 3D record):

const mol3d = ChemDoodle.readMOL(sdfText);
viewer3d.loadMolecule(mol3d);

Exporting from the editor

const editedMol = editor.getMolecule();
const smiles = ChemDoodle.writeSMILES(editedMol);
// Use the SMILES with other parts of the app

In this app

  • Use “Load current SMILES” to load the selected molecule into the editor.
  • Use “Use editor as current” to update the main app with your edited molecule.
  • Use “Render 3D from current” to display the latest fetched 3D SDF in the ChemDoodle 3D viewer.

For complete documentation, visit the official site: web.chemdoodle.com.
